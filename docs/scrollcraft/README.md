# scrollcraft

Scroll-Storytelling für die Landingpage von Bördesnack24 — Szenenmodell,
Bewegungsableitung, Fallbacks, Release-Audit.

## Aufbau

| Datei | Inhalt |
|---|---|
| `SKILL.md` | Einstieg: Zuständigkeit, Reihenfolge, Gates, harte Regeln |
| `references/truth.md` | Wahrheitsschicht — **hier zuerst nachsehen** |
| `references/audiences.md` | Zielgruppen und Pfade |
| `references/storyboard.md` | Szenenvorlage und Signature Story |
| `references/patterns.md` | Kanon der 18 Bewegungsmuster |
| `references/musterbibliothek.html` | alle 18 Muster lauffähig, im Browser öffnen |
| `references/tech.md` | Stack, Zeitgesetz, Budgets, Rechenkerne |
| `references/assets.md` | Herkunft, KI-Umgang, Aufnahmeanleitung |
| `checklists/` | Gates, Szenen-QA, Release |
| `scripts/` | Audit, Bildsequenzen, Screenshots |

## Pflege

Zum Ändern: Datei anpassen, `CHANGELOG.md` ergänzen, Ordner neu als ZIP packen,
hochladen. Der Skill ersetzt dabei die vorherige Fassung.

**Was regelmäßig gepflegt werden muss:** `references/truth.md`. Sobald der
erste Automat läuft, die App im Store ist oder eine Standortzusage vorliegt,
ändert sich der Zeitform-Filter — und damit, was auf der Seite stehen darf.

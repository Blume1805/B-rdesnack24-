# Auftragsverarbeiter und ihre Verträge (Art. 28 DSGVO)

Stand 17.11.2026. Zielbild R1: Für jeden Dienst, der für Bördesnack24
personenbezogene Daten verarbeitet, liegt der Vertrag zur Auftragsverarbeitung
(AVV, englisch DPA) als PDF im Ordner `Verträge/Datenschutz` der GbR.
Kein Rechtsgutachten; die Fundstellen sind am 17.11.2026 recherchiert, die
Fassungen ändern sich. Bei Unklarheit gilt der Text auf der Seite des Anbieters.

| Dienst | Wofür | Personenbezug | Wo der Vertrag liegt | Abgelegt |
|---|---|---|---|---|
| Supabase | Datenbank, Anmeldung, Dateien, Server-Funktionen | ja, alle Kundendaten | <https://supabase.com/legal/dpa> (aktuelles PDF unter `supabase.com/downloads/docs/`); gilt laut Anbieter mit den Nutzungsbedingungen, gegengezeichnete Fassung auf Anfrage | ☐ |
| Resend | E-Mail-Versand (Anmeldung, Belege, Kündigung) | ja, E-Mail-Adresse, Inhalt | <https://resend.com/legal/dpa>, unterschriebene Fassung als PDF verlinkt; bindend mit Annahme der Nutzungsbedingungen | ☐ |
| Hostinger | Landingpage, künftig App-Dateien, E-Mail-Postfach | Server-Protokolle (IP), Postfach | <https://www.hostinger.com/legal/dpa>; Teil der Nutzungsbedingungen | ☐ |
| sevDesk | Buchhaltung, Rechnungen | ja, Rechnungsempfänger | <https://sevdesk.de/datenschutz/> → Abschnitt Datenschutzdokumente → Auftragsverarbeitungsvertrag | ☐ |
| DocuSign | Unterschriften Verträge | ja, Name, E-Mail der Unterzeichner | <https://www.docusign.com/legal/terms-and-conditions/data-protection-attachment> | ☐ |
| CleverPay | Kartenzahlung am Automaten | ja, Zahlungsdaten | **nicht öffentlich gefunden** — beim Anbieter anfordern; prüfen, ob er als eigener Verantwortlicher handelt (Zahlungsdienstleister, DSK-Kurzpapier Nr. 13) | ☐ |
| Lovable | Entwicklung der Landingpage | nur, wenn Formulardaten über Lovable laufen | <https://lovable.dev/data-processing-agreement>; nach Anbieterseite in Business- und Enterprise-Tarifen enthalten — Tarif prüfen. Nach dem Umzug der Landingpage zu Hostinger ggf. kein Personenbezug mehr | ☐ |
| GitHub | Quellcode, automatische Tests, Auslieferung | im Code keine Kundendaten (so soll es bleiben) | <https://github.com/customer-terms> → GitHub Data Protection Agreement; gilt für Team/Enterprise. Bei Free ohne Kundendaten im Repository voraussichtlich nicht nötig | ☐ |

**Offene Punkte:** Liste der Unterauftragnehmer je Anbieter mit ablegen (meist
auf derselben Seite verlinkt); Datum des Abrufs auf jedem PDF notieren.

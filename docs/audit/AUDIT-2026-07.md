Auditumfang: gesamte Codebasis (Flutter/Dart, Supabase/PostgreSQL, Edge
Functions, CI/CD, Doku, Rechtstexte) gemäß Masterprompt Schritt 1–19.

Die Plattform ist in einem **guten bis sehr guten Zustand**: konsequente
Clean Architecture, 0 Analyzer-Findings, 64/64 Tests grün (inkl.
Golden-/Kontrast-Tests), **100 % RLS-Abdeckung** aller Public-Tabellen,
vollständige Rechtstexte (Impressum, Datenschutz, AGB, Widerruf,

ERROR. Handlungsbedarf besteht auf Stufe „hoch" ausschließlich bei
Defense-in-Depth und Skalierungs-Performance (Details Kapitel 12);
diese Maßnahmen wurden im Zuge dieses Audits direkt umgesetzt
(Migration `0054_perf_hardening.sql`, Kapitel 13).

## 3. Sicherheitsbewertung

Basis: Supabase Security-Advisors (77 Findings, alle Stufe WARN) +
Katalogprüfungen + frühere Härtungsrunde (Task #58: RLS-Lücken,
anon-Grants, `search_path`, `security_invoker`-Views).

* **RLS: 100 % Abdeckung.** Keine Public-Tabelle ohne aktivierte Row
  Level Security (Katalogabfrage, 0 Treffer).
* **4 SECURITY-DEFINER-RPCs für `anon` ausführbar**
  (`choose_subscription_plan`, `finance_balance_kpis`, `product_detail`,
  `upsert_finance_balance`). Alle vier guarden intern über `auth.uid()`
  bzw. Gesellschafter-Rollenprüfung mit RAISE — ein anonymer Aufruf
  schlägt fehl. Dennoch verletzt der Grant das Least-Privilege-Prinzip
  → **behoben** (REVOKE in Migration 0054).
* **71 SECURITY-DEFINER-Funktionen für `authenticated`**: erwartetes
  Muster (RPC-Layer mit internen Guards + `search_path`-Härtung aus
  Task #58). Akzeptiert; neue Funktionen müssen dem Guard-Muster folgen.
* **Leaked-Password-Protection (Auth-Setting) deaktiviert**: bewusst
  kompensiert durch clientseitige HIBP-k-Anonymity-Prüfung (Task #59).
  Empfehlung: zusätzlich serverseitig im Dashboard aktivieren (nicht per
  Migration setzbar) → offener Punkt, Aufwand ~2 Minuten manuell.
* **`pg_net` im Schema `public`**: von Supabase so installiert; die
  Extension unterstützt kein `ALTER EXTENSION … SET SCHEMA`. Zugriff ist
  auf `postgres`/`service_role` beschränkt. Akzeptiertes Restrisiko,
  dokumentiert.
* Kein `http://`, keine Secrets im Code (dart-define-Injektion),
  JWT-Verify auf allen Edge Functions außer signierten Webhooks.

## 6. Performancebewertung

* Web-Startzeit: deferred loading, lokales CanvasKit, WebP-Hero,
  SW-freier Erstboot mit nachgelagerter PWA-Registrierung (Task #62, #71).
* **54 RLS-Policies re-evaluieren `auth.uid()` pro Zeile**
  (`auth_rls_initplan`): bei wachsenden Tabellen (purchases, logs)
  messbarer Overhead → **behoben** (Rewrite auf `(select auth.uid())`,
  Migration 0054).
* **33 Foreign Keys ohne Index**, darunter heiße Pfade (`nayax_sales`,
  `purchases`, `purchase_items`, `inventory`, `machine_slots`,
  `offer_activations`) → **behoben** (generierte Covering-Indexe,
  Migration 0054).
* 27 mehrfach-permissive Policies (WARN): funktional korrekt, aber je
  Zeile werden mehrere Policies evaluiert. Konsolidierung ist semantisch
  heikel (Rollen-Matrix) → bewusst als „mittel/offen" belassen, mit
  Regel: neue Policies je Tabelle/Aktion zusammenfassen.
* 20 ungenutzte Indexe (INFO): Demo-Traffic ist nicht repräsentativ —
  **nicht** gelöscht; Beobachtung nach Go-Live.

## 13. Umgesetzte Verbesserungen (dieses Audit)

* Migration **`0054_perf_hardening.sql`**:
  * `REVOKE EXECUTE` für `anon` auf den 4 o. g. RPCs — Befund bei der
    Umsetzung: der Grant lief über `PUBLIC` (Default bei
    `CREATE FUNCTION`), ein Revoke nur für `anon` ist wirkungslos;
    korrekt ist `REVOKE … FROM PUBLIC` + expliziter Grant an
    `authenticated`/`service_role` (per `has_function_privilege`
    verifiziert: `anon=false`, `authenticated=true` für alle vier);
  * generischer initplan-Rewrite aller betroffenen Policies (aus
    `pg_policies` generiert, idempotent);
  * generierte `CREATE INDEX IF NOT EXISTS` für alle unindizierten FKs.
* Verifikation: Advisors erneut ausgeführt (Ziel: 0 anon-Findings,
  0 initplan-WARN, 0 unindexed-FK-INFO), `flutter analyze` + 64 Tests
  unverändert grün (keine App-Änderung).
* Vorherige Session (gleicher Auditlauf): Temperatur-Export-500 behoben
  (WinAnsi-Sanitizer), iOS-PDF-Anzeige auf nativen Viewer umgestellt,
  Dokument-Typografie vereinheitlicht.
